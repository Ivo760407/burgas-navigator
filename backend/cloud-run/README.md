# Burgas Navigator Cloud TTS

This service keeps Google Cloud credentials off the Flutter APK and requires Firebase App Check before generating audio.

## Endpoint

- GET `/health`
- POST `/tts`

Request:

```json
{
  "text": "Вие сте в Бургас, на улица Александровска 1.",
  "language": "bg"
}
```

The response is an MP3 generated by Google Cloud Text-to-Speech.

## Protection

`POST /tts` requires a valid Firebase App Check token in the `X-Firebase-AppCheck` header.

The Flutter app activates Android Play Integrity / iOS App Attest in release builds and the App Check debug provider in debug builds.

Cloud Run verifies the token with Firebase Admin before processing the request. Missing or invalid tokens receive HTTP 401.

The service also limits each observed client to 30 requests/minute, rejects bodies over 8 KB, and limits TTS text to 300 characters.

App Check is an application/device-attestation layer, not a guarantee that a determined attacker can never abuse an endpoint. Keep server-side rate limits and Google Cloud quotas/budget monitoring enabled.

## Google Cloud / Firebase setup

1. Create/select a Google Cloud/Firebase project.
2. Enable Cloud Text-to-Speech API.
3. Add the Android and iOS apps to the Firebase project.
4. Configure Firebase App Check: Android Play Integrity, iOS App Attest.
5. During development, register App Check debug tokens for debug builds.
6. Create a dedicated Cloud Run service account with permission to use Text-to-Speech and Firebase App Check token verification (`roles/firebaseappcheck.tokenVerifier`).
7. Deploy this directory to Cloud Run.
8. Use Application Default Credentials from the Cloud Run service account; never create or commit a service-account JSON key.
9. Set the deployed HTTPS URL as Flutter's `CLOUD_TTS_URL` using `--dart-define`.
10. Prefer restricting Cloud Run ingress/access so the service is not an unrestricted public backend. App Check remains enforced at the application layer.

Firebase platform configuration files are project-specific and should be generated after the Firebase project exists. Never commit service-account private keys or Google Cloud credentials.

## Supported voices

The initial mapping uses Google Cloud Chirp 3 HD voices for Bulgarian, English and German. The voice names can be changed centrally in `server.js` without shipping Google credentials to the app.
