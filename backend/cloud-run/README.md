# Burgas Navigator Cloud TTS

This small HTTP service keeps Google Cloud credentials off the Flutter APK.

## Endpoint

- GET `/health`
- POST `/tts`

Request:

```json
{
  "text": "Вие сте в Бургас, на улица Александровска 1.",
  "language": "bg"
}
```

The response is an MP3 generated by Google Cloud Text-to-Speech.

## Google Cloud setup

1. Create/select a Google Cloud project.
2. Enable the Cloud Text-to-Speech API.
3. Create a dedicated service account with permission to use Text-to-Speech.
4. Deploy this directory to Cloud Run.
5. Give the Cloud Run service access to the service account without putting a service-account JSON key in the repository.
6. Set the deployed HTTPS URL as Flutter's `CLOUD_TTS_URL` using `--dart-define`.

For production, put the endpoint behind authentication/rate limiting or another abuse-control layer. Do not put Google Cloud credentials or a Google API key in Flutter code, GitHub Actions, or the APK.

## Supported voices

The initial mapping uses Google Cloud Chirp 3 HD voices for Bulgarian, English and German. The voice names can be changed centrally in `server.js` without shipping Google credentials to the app.
